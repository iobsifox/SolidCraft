# SOLIDCRAFT

**A fast, lightweight Minecraft launcher for Windows & Linux.**

This repository hosts the **official releases** of SOLIDCRAFT only.
The source code is maintained privately.

## Download

Grab the latest build from the [**Releases**](https://github.com/iobsifox/SolidCraft/releases/latest) page — every release ships exactly five packages:

| File | What it is |
|---|---|
| `SolidCraft-<ver>-windows-x64-online-installer.exe` | Small Windows installer — downloads everything automatically during setup (internet required) |
| `SolidCraft-<ver>-windows-x64-offline-installer.exe` | Full Windows installer — all files bundled, works completely offline |
| `SolidCraft-<ver>-windows-x64-portable.zip` | Windows portable — unzip anywhere, no installation, everything included |
| `SolidCraft-<ver>-linux-x64-offline-installer.run` | Linux installer — all files bundled, no root required, works offline |
| `SolidCraft-<ver>-linux-x64-portable.tar.gz` | Linux portable — extract and run, everything included |

All packages are **self-contained**: the launcher bundles every runtime file it needs, so there is nothing else to download unless you choose the online installer.

## Highlights

- One-click play: vanilla, Fabric, Forge and NeoForge instances
- Mods via Modrinth integration
- In-app self-updater (update gate with patch notes)
- Cracked / offline account support
- Lightweight: runs on 2 GB RAM, 1 CPU core

## Verification

Each release page lists the exact file names and sizes. Only trust files downloaded from this repository's Releases page.
